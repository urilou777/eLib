À qui s’adresse cette aide ?

Ce guide explique comment les composants techniques d’eLib s’articulent. Il complète le README destiné à l’installation et à l’utilisation quotidienne.

Pour les utilisateurs

Comprendre les deux écrans, le scanner mobile, les sauvegardes et les fichiers de données.

Pour les mainteneurs

Repérer les modules responsables, tester une modification et reconstruire la version Windows portable.

En bref

  • Le PC central héberge le serveur FastAPI et la base SQLite locale.
  • L’interface de caisse reste sur le PC ; le téléphone accède au scanner par HTTPS sur le réseau local.
  • Le build x86 embarque Python, RapidOCR, ONNX Runtime, ses modèles et WebView2.
  • Les ventes validées sont stockées dans SQLite. Les paniers live sont un état temporaire de suivi.

Par où commencer ?

  • Architecture et flux de données
  • Appairage, réseau local et scanner mobile
  • Base SQLite, sauvegardes et restauration
  • Application portable Windows et chaîne de build
  • Structure du code, tests et limites à surveiller
Le code source et les tests restent la référence si cette aide n’est plus synchronisée avec l’application.
