Aide eLib / Distribution

Version portable Windows

Le mainteneur construit l’application ; l’utilisateur final lance seulement l’EXE.

AccueilArchitectureScanner mobileDonnéesInstallation et buildMaintenance

Ce qui est embarqué

  • Python Windows 32 bits et les dépendances de l’application.
  • RapidOCR, ONNX Runtime x86 et modèles OCR.
  • Runtime fixe Microsoft WebView2 x86 pour la fenêtre native.
  • Interface web, API et ressources statiques.

L’exécutable x86 fonctionne sous Windows 32 bits et 64 bits. Il n’exige pas une installation Python ou WebView2 sur le poste utilisateur.

Construire l’EXE

Sur le poste de développement, installer Python 3.10 32 bits puis lancer depuis la racine du projet :

py -3.10-32 tools\build_windows_x86.py

Le script vérifie l’architecture, installe les dépendances binaires épinglées, télécharge et vérifie le package WebView2, puis lance PyInstaller. Le livrable est créé dans dist_win32\eLib.exe. C’est le seul dossier de distribution produit par ce build x86 ; dist est un ancien dossier et son exécutable ne doit pas être utilisé.

Après le build

  • Tester l’ouverture d’une fenêtre native sur une machine cible représentative.
  • Tester l’OCR avec l’image d’un livre réel.
  • Tester une vente et une sauvegarde/restauration dans un environnement de test.
  • Distribuer l’EXE avec le dossier data uniquement s’il s’agit de transférer une base existante.

Pour déplacer ou restaurer les données sans mélanger plusieurs copies, consulter Données, sauvegarde et restauration.

Maintenance : le runtime WebView2 fixe est volumineux et doit être reconstruit avec les mises à jour de sécurité. Le support x86 d’ONNX Runtime est limité ; conserver les versions compatibles documentées dans requirements.txt.
