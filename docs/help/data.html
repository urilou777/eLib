Données, sauvegarde et restauration

La base SQLite contient les données métier. Les copies de sauvegarde se trouvent dans le dossier local de l’application.

Emplacement

En mode portable, data/ est créé à côté de l’exécutable. En mode source, il se trouve à la racine du dépôt.

Fichier ou dossierContenu
data/librairie.dbCatalogue, origines, lots, ventes, paiements, trésorerie, réservations et audit.
data/devices.dbAppareils mobiles appairés, jetons hachés et profils connus.
data/backups/Snapshots SQLite et exports de classeurs selon la configuration actuelle.
data/certs/Clés et certificats TLS locaux nécessaires au scanner mobile.

Garanties et précautions

  • SQLite utilise le mode WAL pour la gestion des écritures et accès simultanés.
  • Les snapshots SQLite utilisent l’API de sauvegarde SQLite pour produire une copie cohérente.
  • Les écritures de fichiers utilisent des fichiers temporaires puis un remplacement lorsque c’est applicable.
  • L’application propose la restauration depuis l’écran de sauvegardes et crée une copie de précaution.
Important : une sauvegarde stockée sur le même disque ne protège pas contre la panne ou la perte de l’ordinateur. Télécharger régulièrement une copie sur un support externe et vérifier qu’elle peut être restaurée.

Relations métier principales

  • Les livres possèdent des lots de stock rattachés à une origine.
  • Une vente contient des lignes ; les allocations relient les quantités vendues aux lots et calculent les montants dus.
  • Les packs référencent les livres qui les composent.
  • Les écritures importantes sont enregistrées dans le journal d’audit.

Consulter SCHEMA.md pour la liste détaillée des tables et colonnes. Le schéma exécuté et les migrations se trouvent dans app/db.py.

Transfert vers un autre PC

Arrêter l’application, copier le dossier de données métier vers le dossier data du nouveau poste, puis relancer l’application. Les certificats réseau peuvent devoir être recréés et les téléphones réappairés. Garder une copie intacte de l’ancienne base jusqu’à validation du transfert.
