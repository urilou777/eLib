Tests

Depuis un environnement de développement avec les dépendances nécessaires :

python -m unittest discover -s tests -v

Un changement de schéma doit être accompagné d’une migration compatible et d’un test. Un changement d’API mobile doit vérifier le contrôle d’accès et le parcours utilisateur.

Principes de maintenance

  • Garder la caisse locale sur loopback et limiter strictement les routes LAN.
  • Ne jamais remplacer une donnée de catalogue sans confirmation explicite.
  • Ne pas confondre panier live temporaire et vente persistée.
  • Ne jamais distribuer la base réelle ou les certificats privés dans le dépôt de code.
  • Mettre à jour les tests et cette aide après une évolution d’architecture.
Le compte local sélectionné attribue les actions, mais ne constitue pas à lui seul une authentification forte par mot de passe.
