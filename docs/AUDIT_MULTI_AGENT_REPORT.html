🏛️ Architecture Système & Résilience Hors-Ligne

Double Écoute Réseau Ségréguée

L'architecture applique le principe du moindre privilège réseau :

  • ✓
    Poste de caisse local : 127.0.0.1:8765 (HTTP)
    Strictement confiné à la machine physique. Toutes les opérations administratives (restauration, imports/exports, gestion utilisateurs) sont inaccessibles depuis le réseau.
  • ✓
    Scanner mobile LAN : 0.0.0.0:8766 (HTTPS TLS 1.3)
    Cloisonné aux téléphones appairés par QR code. Liste blanche minimale (scan, composition panier, validation de vente).

Persistance & Anti-Corruption SQLite WAL

Protection absolue contre les coupures brutales de courant et les arrêts inopinés :

  • ✓
    Mode WAL + synchronous=NORMAL
    Permet des lectures simultanées sans verrouiller les écritures. Crash-resilient certifié par les standards SQLite.
  • ✓
    Sauvegarde à chaud non bloquante
    Utilisation de sqlite3.backup() avec écriture dans .tmp puis permutation atomique os.replace().

⚖️ Gouvernance des Données Personnelles (RGPD & CNIL)

Conformité au Règlement Européen (UE) 2016/679 et à la Loi Informatique et Libertés.

1. Principe de Minimisation (Art. 5.1.c)

Les tickets de vente ne comportent aucun identifiant nominatif client (zéro nom, zéro adresse postale, zéro email).

Les qualifications optionnelles (genre, tranche d'âge, profil serviteur) sont purement agrégées et anonymes, interdisant toute ré-identification individuelle.

2. Droit à l'Effacement & Purge (Art. 17)

Les réservations terminées peuvent être purgées et anonymisées en un clic via le nouvel endpoint /api/gdpr/cleanup.

La suppression unitaire masque désormais automatiquement les numéros de téléphone (remplacés par [MASQUÉ RGPD]) dans les traces d'audit.

# Démonstration du mécanisme d'anonymisation RGPD automatique : - INSERT INTO reservations: "Jean Dupont", phone: "0601020304", note: "Client fidèle" + UPDATE reservations SET name='Client RGPD #12', phone=NULL, note='[Données personnelles anonymisées RGPD]' # Dans le journal d'audit : snapshot_before.phone = '[MASQUÉ RGPD]'
